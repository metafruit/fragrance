Google Sheets Sync

Automatically sync your complete fragrance collection closet directly to your Google Spreadsheet.

Setup Instructions:

  1. Create a new Google Sheet at sheets.new.
  2. In the menu, go to Extensions → Apps Script.
  3. Replace all default code with the ScentSpace script (provided in your project folder as google_sheet_code.js).
  4. Click Save, then click Deploy → New deployment.
  5. Click the gear icon, select Web app. Set execution as Me and Access as Anyone.
  6. Click Deploy, authorize permissions, and copy the generated Web App URL.
  7. Paste the URL in the box above and click Sync!
